## Standing rules for this type
- Exit non-zero on any failure, always. A CLI that reports failure in prose and exits 0 breaks every script that uses it.
- Never write outside an explicitly passed output path, and never overwrite the input in place.
- `--help` must be enough to guess the invocation. If it needs the README, the help text is wrong.
- Treat every input file as attacker-controlled. Fail loudly on malformed input; plausible-looking garbage is worse than a crash, because the user ships it.
