   `Workflow({ scriptPath: "workflows/study-project.js", args: { idea: "<one-paragraph description>", type, constraints } })`
   It studies every aspect (human/market · references · tech · free-gen · risk · team · ship-gate · ladder), adversarially verifies, closes gaps → returns `PROJECT_BRIEF` + a draft operating prompt. **Extract eco** (Python parse of the `.output`, no context load).

   - **DoD (STEP 2) =** a `PROJECT_BRIEF` (structured study return) exists and cites REAL named signals (sources), not vibes. If the workflow could not run (missing tool, args gotcha unrecoverable), do the study by hand-fanning agents — do NOT silently downgrade to a single-shot draft. MATERIALIZE is FORBIDDEN until this artifact exists.
3. **MATERIALIZE** — copy `projects/_TEMPLATE/` → `projects/<name>/`. Write `PROJECT_BRIEF.md`. Fill `PROJECT_OPERATING_PROMPT.md` + `STATUS.md` + `PLAN.md` from the brief.
